## **Best Practices for Images**

### **Hero Image**
- Size: 1200x600px (or larger)
- Format: JPG (optimized)
- Quality: Professional, landscape
- Subject: Nature-inspired preferred

### **Portfolio Images**
- Size: 500x625px (4:5 ratio)
- Format: JPG (optimized)
- Quality: Professional portfolio quality
- Subjects: Diverse project types

### **Optimization**
1. Use TinyPNG.com to compress
2. Keep under 100 KB per image
3. Use proper dimensions
4. Use JPG for photos
5. Use PNG for graphics
