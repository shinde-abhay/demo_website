================================================================================
❓ TROUBLESHOOTING
================================================================================

PROBLEM: "python -m http.server" doesn't work
SOLUTION: You need Python installed
          Visit python.org and install Python 3
          Or use Node.js method instead

PROBLEM: Images not showing
SOLUTION: Check asvana-website/assets/images/ folder exists
          Put your images in this exact folder
          Use correct filenames
          Refresh browser with Ctrl+F5

PROBLEM: Styles look broken
SOLUTION: Hard refresh browser: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)
          Check CSS files are in asvana-website/assets/css/

PROBLEM: Contact form not working
SOLUTION: Currently shows success message only
          To send actual emails, see DEPLOYMENT.md
          Follow backend setup instructions

PROBLEM: "Port already in use" error
SOLUTION: python -m http.server 8001
          Use 8001 or 8002 instead of 8000

For more help, see README.md inside asvana-website/
